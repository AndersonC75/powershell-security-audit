# powershell-security-audit

## Introdução

Este repositório contém scripts PowerShell desenvolvidos para auditoria de segurança em ambientes Windows. O objetivo principal é fornecer ferramentas automáticas que ajudem administradores de sistemas e profissionais de segurança a:

- **Identificar vulnerabilidades** em configurações de sistemas Windows
- **Avaliar conformidade** com políticas de segurança corporativas e padrões da indústria
- **Monitorar mudanças** em configurações críticas do sistema
- **Gerar relatórios** detalhados sobre o estado de segurança do ambiente

## Por que Auditoria de Segurança com PowerShell?

PowerShell é uma ferramenta nativa do Windows que oferece acesso profundo às configurações do sistema operacional. Utilizando PowerShell para auditoria de segurança, você pode:

- Automatizar verificações repetitivas e demoradas
- Obter informações detalhadas sobre configurações de segurança
- Integrar facilmente com outras ferramentas de gestão
- Executar auditorias consistentes em múltiplos sistemas

## Recursos Principais

Os scripts neste repositório cobrem diversas áreas de auditoria de segurança, incluindo:

- Verificação de políticas de senha
- Auditoria de permissões de arquivos e pastas
- Análise de serviços e processos em execução
- Validação de configurações do Windows Firewall
- Verificação de atualizações de segurança instaladas
- Auditoria de usuários e grupos locais

## Como Começar

Para utilizar os scripts deste repositório, certifique-se de ter:

1. Windows PowerShell 5.1 ou superior (ou PowerShell Core 7+)
2. Privilégios administrativos no sistema que será auditado
3. Política de execução configurada adequadamente
